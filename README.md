# Saniya Khanam | Computer Science Engineering Portfolio

Welcome to my personal portfolio website repository! This is a multi-page, responsive, and fully accessible personal portfolio designed and engineered adhering strictly to modern semantic HTML5 standards and WCAG 2.1 AA accessibility guidelines.

## 🚀 Key Features

*   **HTML5 Semantic Architecture**: Standardized layout landmark nodes (`<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`, `<article>`, `<section>`) ensuring structural integrity and natural SEO crawling.
*   **WCAG 2.1 AA Compliance**:
    *   **High Color Contrast**: Contrast ratios exceeding WCAG AAA standards for normal body text and interactive teal links.
    *   **Visible Focus States**: Custom `:focus-visible` outline indicators to ensure comfortable and visible keyboard tab navigation.
    *   **Keyboard Accessibility**: A functional "Skip to Content" link, trapped tab focus inside the mobile drawer navigation, and exit controls mapped to the `Escape` key.
    *   **Screen Reader Optimization**: Explicit label-input associations, custom `aria-describedby` error fields, status live regions (`aria-live="polite"`), and hidden screen reader annotations (`.visually-hidden`).
*   **SEO-Optimized Metadata**: Open Graph protocol tags, Twitter card tags, author descriptors, index configurations, and canonical URL elements on all pages.
*   **Premium Theme Design**: Modern space-dark theme with HSL color variables, fluid typography (`clamp()`), and responsive layouts (CSS Grid and Flexbox).

## 💻 Running the Project Locally

To run the application locally without downloading external dependencies, you can use Python's built-in HTTP server:

1.  Clone the repository:
    ```bash
    git clone https://github.com/saniyakhanam13/portfolio.git
    cd portfolio
    ```
2.  Start the HTTP server:
    ```bash
    python -m http.server 8080
    ```
3.  Open your browser and navigate to:
    ```text
    http://localhost:8080
    ```
